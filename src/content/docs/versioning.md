---
title: Versioning
description: How the Stocksmith API is versioned. The beta carries no promise.
---

Version one of the API (`/api/v1`) stays stable. Breaking changes only come in a new
version, and you get six months' notice before one arrives. Security fixes can skip the
notice. The beta carries no promise: nothing on this page applies while the API is in
beta.

## The MCP server

The address of the [MCP server](/agents/) gets the same six months' notice before it
changes. The MCP tools can change at any time.
